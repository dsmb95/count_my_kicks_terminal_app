# Count My Kicks
A terminal application that helps moms in the third trimester keep track of fetal kicks and assist them with kick counts. This is a quick project to practice my python skills.

## Prerequisites
 - Python 3 installed

## Setup
1. Clone the repository
    git clone [https://github.com/dsmb95/count_my_kicks_terminal_app.git](https://github.com/dsmb95/count_my_kicks_terminal_app.git)

## Usage
1. Run on terminal
```bash
python3 count_my_kicks.py
```
2. Answer "y" for yes or "n" for no when prompted by the question.
3. A csv file will automatically be created called **kicks_data.csv**.
4. Check kicks_data.csv to see your kick counts for the day.

## Technologies Used
 - **Language**: Python3
 - **Modules/Libraries**: datetime, csv, os
